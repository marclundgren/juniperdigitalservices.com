# Juniper Digital Services

Company website for Marc Lundgren, deployed as a standalone GitHub Pages site.

## Publish on GitHub Pages

1. Open **Settings → Pages** in the `marclundgren/juniperdigitalservices.com` repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then save.

The expected URL is `https://marclundgren.github.io/juniperdigitalservices.com/`.

When a custom domain is ready, add it under the same Pages settings and create the DNS records GitHub provides.
